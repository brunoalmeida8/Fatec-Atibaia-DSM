Referencias de restrição de FK:
Cacate - cascata
	aparga a pai a filha apaga tbm
	se apagar uma linha na tabela que tem uma PK sendo referenciada em outra tabela com o FK
		as LINHAS que referenciaram aquela pk excluida somem 
	se apagar o que a FK ta referenciando apaga a LINHA;

Restrict - restrito
	não consegue apagar a pai se tiver uma filha referenciando ela;
	nao apaga uma linha que tem PK sendo referenciada em outra tabela como FK;
	
set null
	se apagar a pai, a filha fica com campo null
	se apagar a linha na tabela que tem uma PK sendo referenciada em outra tabela com FK
		as LINHAS que referenciaram aquela PK excluida ficam com o valor NULL;
	OBS - o campo nao pode ser NOT NULL;
